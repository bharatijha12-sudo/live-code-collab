# Live Code Collab

A real-time collaborative coding platform inspired by VS Code.

## Features

- Real-time code synchronization
- Room-based collaboration
- Multi-language execution
- Chat system
- File explorer
- Folder hierarchy
- Theme system
- Workspace persistence
